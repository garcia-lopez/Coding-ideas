# ✨ Coding Ideaa

A personal collection of fun coding projects inspired by my friends.  
Each project is a small experiment where I explore creativity, UI design, and frontend logic using vanilla JavaScript, HTML, and CSS.

---

## 🌸 About the Project

**Coding Ideaa** is a space where I turn ideas into small interactive experiences.  
Some projects are playful, some are aesthetic, and others are just me practicing and learning new things.

---

## 🛠️ Built With

- HTML5  
- CSS3  
- Vanilla JavaScript
